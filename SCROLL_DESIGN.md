# Underground Quantum Leap — scroll design

Reference reviewed November 4, 2026: https://pear.no/?ref=siteinspire and its publicly served assets/index-BhJdAf8K.js bundle.

## Investigation

The live reference was visited and scrolled through multiple scenes. DOM inspection found persistent canvases, fixed media, a chapter HUD, and footer video. Inspection of the public JavaScript identified native WebGL shader compilation, a Bayer threshold treatment, video textures, requestAnimationFrame-driven rendering, interpolated scroll state, and targeted frame sequences. Its desktop renderer also intercepts scrolling. These findings were used as a technique reference; no Pear images, videos, shaders, or application code were copied.

The supplied November 4 recording demonstrates the continuous scene progression. The supplied November 3 recording provides the underground aesthetic and locally processed footage.

## Implementation

- `UndergroundScrollStage.tsx`: one fixed Canvas 2D stage, capped pixel ratio and frame frequency, scroll interpolation, pointer-responsive stipple rings, Bayer-processed film texture, perspective waves/grids, five chapter treatments, restrained red tracking accents, and a constellation connection to the visible chat input.
- Scroll position scrubs a silent same-origin video. Short keyframe intervals improve seeks. Chapter opacity changes are interpolated. The video is decorative and makes no candidate experience claim.
- The rendered chapter follows actual section positions. The telemetry readout measures the physical document scroll from 0–100%; section lengths determine where chapters begin.
- Native page scroll and anchor navigation remain available; no wheel or keyboard scrolling is intercepted. The scene is visually smoothed independently of document scroll.
- The fixed HUD provides a ruler, current chapter, moving progress indicator, FX toggle, resume download, and contact action. A native dialog provides the five chapter links with focus containment and Escape dismissal.
- `page.tsx`: a full-height editorial introduction, proof pillars, project dossiers with sticky diagrams, experience/education, ambassador, and closing mark over a continuous environment.
- `VirtualAmbassador.tsx`: visual framing and typography updated; request construction, transient history, state/locking, and approved-answer link rendering retain their behavior.
- Local Instrument Serif and Fira Code provide typography without remote font calls.
- Reduced motion: system preference initializes the toggle; static procedural scenery remains, media scrubbing/cursor displacement stops, and CSS transitions are removed by the system media query. Hidden documents stop the render loop.
- Media failure or unavailable canvas leaves ordinary readable editorial content and navigation available.
